## ④ 原创声明与 AI 模型使用说明

### 原创性

- 本项目为个人自研，延续个人此前的「简历优化助手」（原项目为个人赛前私有版本，无公开仓库地址），在此基础上新增模拟面试、简历库与可视化编辑器等能力。
- 未拷贝任何第三方开源项目的业务代码或模板文件；9 套简历模板均为自研 HTML/CSS 排版。
- 使用的第三方基础库：pdf.js（Apache-2.0，PDF 渲染）、中文字体子集（随项目分发，仅用于导出）；版权归原作者，仓库保留其许可文件与声明。
- 未使用他人素材、未调用闭源商业模板。

### 48 小时内新增

1. **模拟面试**：按岗位/JD 生成问题与追问，逐题作答，结束生成评分报告与改进建议，保留历史记录。
2. **简历库**：多份简历管理、上传解析、粘贴导入、真实缩略图；新建流程先选模板。
3. **九套模板**：经典、两栏、模板标题、时间轴、极简、学术、创意、作品集、瑞士风；全部一页成稿，可按模板重置主题色与字体。
4. **可视化编辑器**：模块增删、排序、隐藏，头像、主题色、字体、行高、姓名字号；三栏可拖拽调宽，实时预览。
5. **六格式导出**：PDF（按 A4 自动分页）、DOCX、PNG、Markdown、TXT、JSON；另有一键「紧凑一页」。
6. **优化闭环**：JD 诊断 → 逐条采纳 → 直接回写当前简历 → 可撤销，简历卡预览与分数同步。
7. **工程与体验**：BYOK 服务商设置（10 家品牌图标、温度说明、错误提示中文化）、访问码保护、本地自动备份、国内可直连的 CloudBase 部署。

### AI 模型与工具

- **开发过程**：使用 OpenCode + 百灵（bailing）平台的 `deepseek-v4.1-flash` 辅助编码、文案与自动化验收；使用 Edge headless + CDP 编写回归脚本，Node.js 26 运行构建与本地服务，CloudBase CLI 部署。
- **产品运行时**：不绑定具体模型。用户在「API 设置」里自选服务商并填入自己的 Key，前端通过 OpenAI 兼容接口调用；默认 DeepSeek，可切换通义千问、豆包、Kimi、智谱 GLM、硅基流动、OpenRouter、OpenAI、Gemini 或自定义中转。
- **未直接调用** Ling-3.1-flash / Ling-3.2。产品对任何 OpenAI 兼容端点开放，如需接入：在「API 设置」选择「自定义 / 中转」→ 填服务商 Base URL、API Key、模型名（如 `ling-3.1-flash` 或 `ling-3.2`）→ 点「获取模型列表」→「测试连接」→「保存并使用」。Key 只保存在本机浏览器，请求经同源代理转发。
- **无 Key 降级**：未配置模型时自动使用规则版优化，保证评委打开即可体验，不会因缺少 Key 卡住。

### 数据与安全

- 简历正文、API Key 默认只存浏览器 `localStorage`，不上传站点；站点不内置共享 Key。
- 仓库与演示站点均不包含真实密钥；部署时通过环境变量注入访问码。
